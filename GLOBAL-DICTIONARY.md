# Основная русская конфигурация, сессии и постоянные замены

- Основной HTTPS-адрес и прежний `:8443` обслуживает конфигурация rules + GLiNER RU + apararti/privacy-filter-ru на 8845. Qwen и боты не изменяются.
- Старые зашифрованные сессии импортируются без изменения ID, префиксов, ключей и сроков. После проверки идентичности данных старая служба 8844 останавливается и её дубли удаляются, чтобы удаление сессии отзывалo единственную рабочую копию ключа.
- Исходные имена и снимок словаря шифруются отдельным ключом сессии. Для старых загрузок имя неизвестно. Оригинал и результат хранятся зашифрованно до одного исходного срока сессии (90 дней от загрузки); оба доступны для скачивания. Исходный DOC хранится отдельно от рабочей DOCX-конвертации. Ошибки анализа не сокращают срок. Ранее удалённые оригиналы не восстанавливаются задним числом.
- Выходное имя нейтральное, без исходного имени: оно тоже может содержать чувствительные сведения.
- Словарь шифруется мастер-ключом в SQLite. Сохраняется до удаления пользователем. Публичные журналы не содержат исходных значений и имён файлов.
- Совпадения точные, регистрозависимые, с границами слов, включая разрывы Word runs. Длинная запись выигрывает у вложенной короткой. Остаток более широкого модельного диапазона не скрывается молча: такой конфликт остаётся для проверки.
- Постоянный алиас имеет формат `[[ORG-GLOB-001]]` (тип и уникальный номер). Можно указать свободный номер; ранее использованный нельзя назначить новому значению. При изменении исходного значения/типа назначается новый алиас. Выключение/удаление действует только на будущие загрузки.
- Каждая загрузка сохраняет снимок словаря. Снимки и таблицы восстановления старых сессий не переписываются при изменении правил.
- Для восстановления только глобальных алиасов пользователь явно выбирает исходную сессию. В смешанном документе сессионные алиасы определяют её автоматически. Текущий глобальный словарь никогда не используется вместо исторической таблицы.
- Служебный код скрыт из основной таблицы; доступен в подробностях экспортированной сессии и выборе сессии восстановления.

## Проверка и откат

`tools/promote_russian_service.py prepare` сохраняет исходники/launchd-конфигурацию/Tailscale-маршрут; `merge` проверяет и копирует только зашифрованные данные старой службы. При коллизии ID, префикса или повреждении копирования переключение запрещено.

До `retire` возможен откат маршрута на 8844. После `retire` маршруты остаются на 8845: откатываются только исходники/launchd из резервной копии, не база данных. Перед таким откатом нужно запретить изменения и работу с новыми сессиями `GLOB`, которые старый код не поддерживает. Не запускать старую службу с пустым хранилищем как основной интерфейс. Для обычного исправления предпочтительно обновление вперёд с сохранением формата словаря.
