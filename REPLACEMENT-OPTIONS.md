# Категории и короткие плейсхолдеры

Новые загрузки через интерфейс и HTTP API используют плейсхолдеры версии 2.
Все 19 категорий включены по умолчанию, язык — русский. Английский выбирается
независимо от языка документа: сам текст не переводится.

Категории: ФИО, организации, адреса/города, email, телефоны, URL, паспортные
номера, личные идентификаторы (СНИЛС/SSN), налоговые номера, регистрационные
номера, банковские реквизиты, номера документов, суммы/коммерческие условия,
даты, время, аккаунты, секреты, IP, прочие персональные данные.

IBAN, SWIFT, БИК, счета и карты объединены в банковские реквизиты. Не обещается
отдельная гарантированная детекция каждого международного вида идентификаторов.
Для явно подписанных «СНИЛС» и «SSN» добавлены правила выделения номера без
подписи; подтверждается форма записи, не принадлежность или действительность.

## Семантика

- Классификация остаётся локальной и полной. Снятые категории отфильтровываются
  после определения точного типа, до применения словаря и сборки замен.
- Фильтр повторно применяется при чтении/изменении решений; секреты и словарь
  не могут незаметно вернуть отключённую категорию.
- Объединённая область нескольких выбранных типов может получить общий тип PII.
  Это объединение уже выбранных диапазонов, не повторное включение категории.
- Категории зависят от качества классификации. Модель может ошибаться или
  выделить слишком широкий фрагмент. Пользователь видит диапазон замены и
  предупреждение о данных, которые могут остаться в файле.
- Пустой список и неизвестные категории/языки отвергаются до создания сессии.
- Настройки сохраняются в зашифрованных метаданных и результатах сессии.
  Перезапуск, повторный анализ и экспорт используют тот же выбор.
- Фильтрация не отключает модели и не меняет удаление изображений.

## Обозначения

Примеры: `[ФИО_1]`, `[адрес_1]`, `[почта_1]`; `[Name_1]`, `[Address_1]`,
`[Email_1]`. Нумерация обычных значений отдельная для каждого типа. Одинаковый
тип и точное значение имеют один плейсхолдер; падежные формы хранятся отдельно.
Коллизии с номерами постоянных замен пропускаются.

Постоянные замены сохраняют закреплённый номер и пользовательское название,
например `[Заказчик_7]`. Пользовательские названия не переводятся автоматически.
При отсутствии названия выбирается имя типа на языке сессии. Внутренняя запись
словаря остаётся прежней для обратной совместимости.

Гиперссылки используют безопасный адрес на `wordshield.invalid` с обратимой
кодировкой нового токена. Исходная ссылка не сохраняется в экспортированном
адресе. Токены в MD не экранируются обратными слешами.

## Восстановление и совместимость

Короткий токен не содержит идентификатор сессии и не позволяет отличить два
документа с `[ФИО_1]`. Для версии 2 требуется явно выбранная исходная сессия.
Предпочтительный путь: карточка документа → «Восстановить исправленный файл».
Неправильно выбранная сессия может содержать совпадающие короткие токены;
поэтому выбор должен проверять пользователь, а не эвристика программы.
Неизвестные токены не угадываются; пропуски и дубли отражаются в отчёте.

Старые сессии не переписываются: длинные алиасы, сохранённые результаты и
автоматическое определение старого префикса продолжают работать. Python-вызов
`begin_session` без `options` сохраняет прежнее поведение для существующих
внутренних инструментов. HTTP всегда передаёт v2-настройки, включая значения
по умолчанию. Пример multipart-поля `options`:

```json
{"language":"en","categories":["person","email","passport"]}
```

## Развёртывание и откат

Схема SQLite не меняется. Изменения добавляют метаданные, не мигрируют файлы
или ключи. Перед установкой проверяется отсутствие активного анализа и
сохраняются предыдущий код и launchd-конфигурация.

Старая версия не умеет восстанавливать v2-токены. При откате новые сессии
нельзя считать совместимыми со старым восстановлением: сохранённые результаты
останутся, но для восстановления нужно вернуть v2-совместимую версию.
Каталоги данных и таблицы соответствий при откате не удалять.

Проверки: выбор/исключение категорий, отключённые секреты и словарь, русский и
английский, стабильные повторы, коллизии, гиперссылки, короткие токены между
Word runs, DOCX/MD, неизвестные/удалённые/дублированные токены, старые сессии,
отсутствие доступа между кабинетами и неизменность текста вне замен.
